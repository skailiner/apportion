# APPORTION verification

The original 11 model groups cover fixtures, 160 generated cases, independent quotient-oracle comparisons, exact fractions, tie classes, quota bounds, house-size paradoxes, row/scale invariance and exports.

The consumer revision adds eight groups: invalid-draft preservation; synchronous edit protection before tool calls; locked/cancelled/stale replacements; compact and legacy input round-trips; maximum-size and invalid files; sparse arrays and Unicode; per-group rule comparisons; cutoff ties versus next-pool losses and the 200-place boundary.

Imported evidence outputs are deliberately untrusted. Tests replace them with forged claims and confirm that only validated configuration is restored and every summary recalculated. A large valid legacy report is tested against the 1 MiB input limit. Fixed IDs and priorities survive reordered rows and duplicate names.

Current type, lint, test, build and release checks are recorded in RELEASE.md. Historical live browser checks belong to the original release; no new browser/device or accessibility testing is claimed for this revision. Artifact pattern checks are not a comprehensive security or dependency audit. No new dependency audit was run.
