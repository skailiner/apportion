# Compare three ways to share a limited number of places.

Enter group weights and the available places, then compare three exact proportional rules. Inspect ties and rounding, and explore cases where one more place changes who receives a seat.

## Who it is for

Club and workshop organisers explaining a proportional allocation to participating groups.

## Get a useful first result

1. Decide what the weights represent and whether proportional allocation is appropriate.
2. Enter the groups and the total; apply the inputs before comparing results.
3. Read the group comparison summary: it names who receives different totals across the rules. Inspect relevant ties and check what happens when one more place is added.
4. Download the discussion brief for a meeting. It includes the inputs, exact quota, each rule’s allocation, ties, next-place changes and questions to agree before deciding. Record the group’s actual choice and rationale separately.
5. Save inputs to keep an editable backup. Open saved inputs accepts that file or older APPORTION evidence JSON; outputs are recalculated, not trusted from the file. Cancel the replacement confirmation to keep the current calculation.

## Know the boundary

The app exposes arithmetic, not a universally fairest rule. It does not model rights, need, eligibility or legal requirements. Only use proportional allocation when the group agrees that the chosen weights are appropriate.

Weights are proportions, not demand or capacity limits. An allocation can exceed a group’s weight; if a workshop has group-specific caps or minimum places, this model does not enforce them.

Nothing is autosaved, and there is no undo. Apply or explicitly discard unfinished entries before changing rules/totals, opening examples/files or downloading. A valid new file or example still asks before replacing applied inputs. Save inputs before accepting a replacement if you want to keep both studies. The discussion brief is for sharing, not an editable backup. Downloads include group names and weights; check them before sharing.
